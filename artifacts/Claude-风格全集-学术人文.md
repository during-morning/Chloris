## 一、设计哲学：印刷传统的数字回声

**1. 人文主义的工具观。** Claude 的自我命名是 "thinking partner"（思考伙伴）
而非 assistant（助手）——这不是文案修辞，而是整个视觉体系的伦理基础。
界面必须退居文本之后，如同书页退居于思想之后。产品页的主标题
"**The work behind your best work**" 用整幅衬线大字呈现，没有任何装饰图形，
这正是苏格拉底对话录的排版化：**言语即主角，界面即纸张**。

**2. 摇篮本的血统。** 官方展示衬线字体名为 *Copernicus*——以哥白尼命名，
向 15 世纪印刷革命与科学启蒙致敬。这不是随意的复古趣味：Claude 的视觉
语言整体上是一场"**摇篮本（incunabula） modernization**"——
1450 年代活字印刷的版面秩序（窄栏、衬线、行间疏朗、栏线分隔）
被移植到深色玻璃与浅色纸面上。理解了这一点，所有细节都是必然的：
衬线永不加粗，因为铅字时代的小号大写与加粗是稀缺资源；
栏线（hairline rule）承担分栏，因为早期书页没有卡片盒子。

**3. 博物学的表达层。** Claude 的插画语言不是几何抽象，而是
**18—19 世纪博物学图谱**（natural history plate）：植物铜版画配拉丁学名
（*Iris cuprea*、*Digitalis purpurea*）、剪影容器里装着海与帆船、
纸片标本标签标注 "Clouds / Boat / Ocean"。这是一种**收藏家的世界观**——
把不可捉摸的智能（海、天气、蝴蝶）做成可以编目、贴标签、放入标本罐的
实物。AI 的不可见性被博物馆学的可见性驯服了。

**4. 稀缺性伦理。** 陶土色（clay）是 Anthropic 唯一的彩色签名，但它出现的
频率低到近乎吝啬：一枚星芒徽标、一个主按钮、一支文本光标。
**色彩的出现即是承诺**——凡是陶土所在处，必是最重要的那一个动作。
这是整个体系最值得学习的纪律。

## 二、色彩系统

### 2.1 全值表

| 角色 | 浅色（纸） | 深色（板岩） |
|------|-----------|-------------|
| 画布 | 象牙纸 `#F0EEE6`（Oat） | 暖黑 `#1F1E1D`（Slate） |
| 画布加深 | `#E9E6DC` | `#191817` |
| 凸面（卡片/浮层） | `#FAF9F5` | `#242322` |
| 墨色（正文/标题） | `#191919` | 奶油白 `#F4F2EC` |
| 次级文字 | 暖灰 `#6E6A61` | 暖灰 `#B5AFA2` |
| 主强调（陶土） | `#D97757` | `#E08A66` |
| 陶土容器 | `#F7E7DE` | `#4E2617` |
| 辅助强调（薰衣草） | 容器 `#DEDCF6` / 深字 `#2D2A5E` | `#A5A1E0` |
| 发丝线 | `#E3DFD4`（弱）/ `#C7C1B2`（强） | `#3C3A36` / `#6A655C` |
| 报错 | `#B3392B` | `#F09A8C` |

### 2.2 三条色彩法则

1. **纸与墨是一切。** 画面 95% 由纸（或暖黑）与墨构成。深色模式不是
   "黑底白字"，而是**暖板岩配奶油**——绝对禁止纯黑 `#000` 与纯白 `#FFF`
   大面积相撞，那会杀死纸张的温度感。
2. **陶土稀缺原则。** 单屏陶土出现不超过两处：星芒徽标 + 主按钮；
   例外仅授予文本光标。图标永远单色，永不带彩。
3. **薰衣草是第二声音。** 筛选选中态、NEW 徽章类语义用淡薰衣草
   （`#DEDCF6` 底 + `#2D2A5E` 字），与陶土分工明确、互不稀释。

## 三、字体排印：衬线的独奏与无衬线的伴奏

### 3.1 双声部体制

- **展示层（Display）**：现代衬线（Copernicus，Tiempos 血统）。
  用于大标题、区块标题、**甚至副标题**——这是 Claude 排印最独特的决定：
  副标题也是衬线，只是更小、更灰、行高更疏（≈1.45）。
- **界面层（UI）**：人文无衬线（Styrene 系）。用于按钮、标签、正文、
  辅助说明。几何骨架 + 人文开口，中性而不冷漠。

### 3.2 排印铁律

1. **衬线永不加粗。** 字重锁定 w400—w500。层级靠**字号 + 颜色**表达，
   靠加粗表达层级是排印上的懒惰。
2. **字距随字号收紧。** 44px 级 −1.5~−2%；22px 级 −0.4~−0.5%；
   正文 0；小标签 +0.3~0.4（微开，不做成宽字距工业标签）。
3. **没有全大写宽字距标签。** 眉题（eyebrow）保持自然大小写——
   "Claude Cowork" 而非 "CLAUDE COWORK"。
4. **窄栏即教养。** 正文栏宽约束在 46—60ch（约 620—680px），
   副标题窄至 460px。行长失控是编辑部的大忌。
5. **中文映射**：衬线槽 → Noto Serif SC / 思源宋体；
   无衬线槽 → Noto Sans SC / 苹方。中西文混排时衬线槽统一走宋体系，
   保持"书"的隐喻不断裂。

### 3.3 字阶参考（App 实测值）

```
display  44/−1.8%  衬线 w400   （英雄主标题）
display  30/−0.9%  衬线 w400   （区块英雄）
headline 26/−0.6%  衬线 w500   （页标题）
title    19/−0.2%  衬线 w500   （卡片/对话框标题）
subtitle 17/ 0     衬线 w400 × 1.45 灰  （衬线副标题）
body     16/ 0.1%  无衬线 × 1.6
label    14/w600   无衬线      （按钮）
caption  11/w500 +0.4% 无衬线  （眉题/辅助）
```

## 四、图标语言：细线考古学

- **线重 ≈1.5px**（24 网格），圆端点、圆角拐点——手写的温度，
  机械的秩序。开源对应物：Lucide。
- **永不填充。** 选中态不切换为实心 glyph，而是**墨色加深**
  （暖灰 → 墨）。图标系统里没有"重音"，只有"浓淡"——这直接继承自
  铜版画只有线条没有平涂的技法传统。
- **永不带彩。** 图标是墨的世界，色彩属于按钮与徽标。
- **尺寸阶梯**：导航 24 / 行内 20 / 角标 18 / 英雄区 36—44。

## 五、布局语法：编辑部与展开的书页

**1. 英雄构图（Hero）。** 居中纵轴：细线图标（36—44px）→ 衬线大标题
（可两行）→ 窄栏灰色副标题 → 一对按钮。上下留白 ≥48px。
整页如同扉页（title page）——摇篮本 books open with a hero。

**2. 分隔线网格（Divider Grid）。** Core capabilities 区是范本：
三列内容之间只有 1px 竖线，**没有卡片盒子**。这是报纸/期刊分栏线
（column rule）的直接引用。格内结构：细线图标 → 衬线小标题 → 灰色正文。
凡并列语义，优先栏线而非边框。

**3. 三级栅格**（桌面）：内容列 720px；阅读列 760px；宽列表 960px。
侧栏 248px。窗口越宽，内容越不跟随之——**版心意识**。

**4. 深色即舞台。** 深色页面像剧场：暖黑幕布、奶油字幕、一盏陶土追光。
所有对比都为衬线大字服务。

## 六、控件形制

| 控件 | 形制 | 备注 |
|------|------|------|
| 主按钮 | **墨黑实心药丸**（StadiumBorder），纸色文字 | 浅色下 `#191919`，深色下奶油 |
| 次按钮 | 细描边药丸，墨色文字 | 1px，无填充 |
| 文字按钮 | 药丸热区，墨色 | — |
| 陶土按钮 | 仅授予"唯一决定性动作"（FAB、开始使用） | 单屏至多一个 |
| 开关/复选/单选 | 选中即**墨黑**，白色纸芯 | 不用强调色 |
| 筛选 Chip | 选中 = 薰衣草底深紫字 | NEW 徽章语法 |
| 卡片 | 凸面纸 `#FAF9F5`，**无边框无阴影**，r16 | 靠色阶浮起，不靠描边 |
| 搜索框 | **全圆药丸**，聚焦墨色 1.2px 细边 | — |
| 对话框/菜单 | r16 + 1px 发丝线边 | 深浅同构 |
| SnackBar | 墨黑药丸（浮起） | — |
| 文本光标/选区 | 陶土光标 + 陶土 18% 选区 | 唯一的日常彩色 |
| 分隔线 | 1px `#E3DFD4` | 全局统一 hairline |

**阴影纪律：全局零阴影。** 层级靠色阶（paper → raised → hairline）表达。
elevation 是拟物残留，与印刷语言不相容。

## 七、动效

- 时长三档：120 / 220 / 340ms；曲线 easeOutCubic 进、easeInCubic 出。
- 页面切换用**淡入上移**（FadeUpwards），不做共享轴旋转。
- 减动效（reduce motion）时全部归零——尊重系统的谦逊。
- 原则：动效是"翻页"，不是"表演"。没有任何元素需要弹跳。

## 八、图形表达层：博物馆学四式

这是 Claude 体系里最易被忽视、却最具辨识度的一半——**产品 UI 之外，
品牌叙事之内的插画语法**。四式按抽象度递增：

### 式一 · 博物学图谱（Botanical Plate）
植物铜版画 + 拉丁学名手写体标签 + 圆形画面裁切（似显微镜视野）。
**用法**：知识、分类、命名类主题。色彩：低饱和植物色 + 纸底。
关键元素：学名标签必须用手写体斜体，置于画面左上/右上。

### 式二 · 剪影容器 + 标本标签（Silhouette Vessel）
黑色人首剪影，内部装满海天帆船；三张纸质小标签（"Clouds" "Boat" "Ocean"）
钉在对应元素上。**用法**：心智、内省、"脑中之海"隐喻。
标签铁律：短英文单词、纸片带细阴影、微旋转。此式是 Claude 品牌
辨识度最高的构图，堪称"标志 性镜头"。

### 式三 · 红陶海报字卡（Terracotta Poster）
红陶底（`#C96442` 附近）+ 奶油白衬线大字（如 "Fable 5"）+ 散落的
干压蝴蝶标本 + 隐约方格纸纹。**用法**：命名时刻、版本发布、章节字卡。
这是"字卡"的绝对形制：一句话、一个大字、几只蝴蝶，别无他物。

### 式四 · 复古画意场景（Vintage Storybook Scene）
仿 19 世纪海洋版画/故事书油画：鲸跃于帆船队之间，云层低垂，
低饱和暖调。**用法**：叙事场景镜。动态化时保持"画在动"而非
"摄影机在动"——禁用实拍质感、镜头光晕、film grain。

### 双通道合成律（Chloris 宣传片现行定调）
- **场景镜** 走式四（vintage storybook oil painting）
- **图形镜/字卡** 走式三（flat pastel + 细线圆角框 + token 网格 +
  红陶字卡）
- 式一、式二作为过渡镜与点题镜穿插。
- 媒介参数：H3 生成、默认 4s、768P 草稿、Real-ESRGAN 超分 1080P、
  首帧保真法做文字、卡点切于 BGM 波形。

## 九、禁令清单（Don't）

1. ❌ 纯黑纯白大面积相撞；❌ 纯灰 `#808080`（一切灰都要偏暖）。
2. ❌ 衬线加粗；❌ 全大写宽字距标签；❌ 超过 60ch 的正文行长。
3. ❌ 彩色图标；❌ 陶土铺满背景大面积（字卡除外——那是海报逻辑）。
4. ❌ 阴影表达层级；❌ 卡片套卡片；❌ 渐变按钮。
5. ❌ 拟物图标、双色图标、填充态切换。
6. ❌ 紫蓝渐变玻璃拟态（那是"AI 味"清单之首，Claude 的反面）。
7. 宣传片：❌ Live-action / cinematic / film grain；❌ 文字进剪辑软件
   （文字一律首帧保真预生成）。
